## 빈틈(Gap) 요약 — 재평가

1. **"무료로 커스텀 시퀀스 저장" 자체는 이미 최소 2개 앱(Workout Timer Custom Intervals, GymPulseTimer)이 실제로 제공 중.** ideas-1.md 작성 시점의 가설("경쟁 앱은 광고/유료 시퀀스 제한이 많다")은 일부만 맞음 — Intervals Pro, Seconds 는 실제로 유료 마찰이 있지만, 이미 완전 무료 대안이 시장에 존재해서 "우리가 처음으로 무료 커스텀 타이머를 만든다"는 차별점은 성립하지 않음.
2. **버그로 인한 신뢰 문제(라운드 리셋)**가 한 경쟁 앱에서 발견됨 — 확실한 상태 관리(일시정지해도 완료 라운드 수 유지)만 제대로 해도 최소한의 우위는 가능하나, 이 역시 "고쳐서 이기는" 수준이지 새로운 가치는 아님.
3. **시장이 매우 포화**: 이번 두 번의 검색만으로 직접 경쟁 앱 9개 이상 발견. 인터벌 타이머는 앱스토어에서 가장 흔한 유틸리티 카테고리 중 하나로 보임.
