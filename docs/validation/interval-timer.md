# 검증 — 커스텀 인터벌 운동 타이머 (slug: interval-timer)

> Run #3, T-003. docs/research/interval-timer.md 의 조사 근거로 mission.md §4 기준 재점수 + 반대 논거 + 선정/기각 결론.

## 재점수 (조사 이전 vs 이후)

| 기준 | 이전(ideas-1.md, 근거 없음) | 이후(경쟁 조사 근거) | 근거 |
|---|---|---|---|
| Pain | 4 | 3 | 인터벌 트레이닝이 필요한 사람에게는 실제 수요가 있지만, 이미 무료 대안이 충분히 있어 "못 참을 만큼" 강한 고통은 아님 |
| Gap | 3 | **1** | "무료로 커스텀 시퀀스 무제한 저장"은 이미 Workout Timer Custom Intervals, GymPulseTimer 두 앱이 실제로 완전 무료로 제공 중. 애초에 가정했던 빈틈(유료 마찰)은 Intervals Pro/Seconds 등 **일부** 앱에만 해당하고, 시장 전체의 빈틈은 아님 |
| Feasibility | 5 | 5 | 여전히 순수 로컬 구현 가능 (expo-notifications, expo-av/expo-speech) |

| **합계** | 20 | **15** | 기준(18점) 미달 |

## 왜 실패할까 (반대 논거)

1. **"왜 이걸 새로 써야 하나?"에 답이 없다.** Workout Timer Custom Intervals 는 이미 "완전 무료, 체험판 없음, 무제한 커스텀 라운드"를 제공한다. 우리가 같은 것을 다시 만들어도 사용자가 갈아탈 이유가 없다 — 앱스토어 검색 순위·리뷰 수 자체가 이미 확보된 기존 앱을 이길 유통 채널조차 없다(이건 Expo Go 시연용 MVP라 해당 없다고 반박할 수 있지만, mission.md §1 의 목표는 "누군가 실제로 쓰고 싶어하는 수준"이므로 장기적으로는 문제가 된다).
2. **버그 수정(라운드 리셋)만으로는 차별점이 약하다.** 경쟁 우위가 "남의 버그를 안 만든다"뿐이면, 이는 지속 가능한 차별화가 아니라 최소 기준일 뿐이다.
3. **시장 포화도가 매우 높다.** 단 두 번의 검색으로 직접 경쟁 앱 9개 이상을 발견했다 — 이는 카테고리 자체가 레드오션임을 시사한다. mission.md §4 의 Gap 기준("기존 제품이 해결하지 못하는 빈틈이 명확한가")을 충족하지 못한다.
4. (반론에 대한 재반론 시도) "구현이 쉬우니 일단 만들어보고 나중에 차별점을 찾자"는 논리는 근거 없는 낙관이다 — mission.md §4 는 Gap 점수를 명시적으로 요구하며, 지금 시점에 빈틈이 없다는 근거가 이미 확보된 상태에서 이를 무시하고 진행하는 것은 §4(비판적 검토 태도)의 "근거 없는 주장 금지"에 위배된다.

## 결론: 기각 (REJECT 제안)

interval-timer 후보는 재점수 15점으로 mission.md §4 기준(18점 이상)에 미달하며, 핵심 근거(Gap)가 조사 이전 가정과 달리 실제로는 이미 충족된 시장임이 확인되었다. **이 후보를 기각**하고 다음 우선순위 후보(split-bill, T-004)로 넘어갈 것을 제안한다.

(주: 이 문서의 결론은 Critic 게이트 통과 전까지는 잠정적이다. Critic 이 REJECT 를 확정하면 phase 전이 규칙(§3 "기각"/"pivot" 경로)에 따라 다음 후보로 진행한다. PASS 판정은 이 경우 "기각 결론이 타당함을 확인"하는 의미로 해석한다.)
